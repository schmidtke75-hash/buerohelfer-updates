# Bürohelfer – Updates

Hier liegt nur die fertige Mac-App (für Apple-Silicon- und Intel-Macs). Installierte Bürohelfer finden neue Versionen
selbst: Klick auf die Versionsnummer oben, dann „Update installieren“.

Neuinstallation: [Buerohelfer.zip](https://github.com/schmidtke75-hash/buerohelfer-updates/raw/main/Buerohelfer.zip) laden, doppelklicken und
„Buerohelfer“ in den Ordner Programme ziehen. Beim ersten Start Rechtsklick → Öffnen.

Aktuelle Version: 1.98.1
